# Legacy Spec: Initial WispWire TUI design

This file preserves the project record for an already approved Superpowers specification.

## Summary

Defined the original architecture: TShark/dumpcap integration, packet summaries, SQLite index, read-only TUI, live capture boundaries, safe temporary segments, and staged delivery.

## Current Language Standard

WispWire now uses English for documentation, user-facing text, comments, tests, and contributor guidance. New work should create fresh English specifications instead of extending this legacy record.
